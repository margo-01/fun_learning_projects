Fun and beginner-friendly projects


chem_tutorials: my implementation of the electronic structure tutorials: https://pycrawfordprogproj.readthedocs.io/en/latest/index.html
Closed-Shell Hartree-Fock implementation works for any molecule, as long as the structure (in .dat format) and the one- and two-e integrals (can be calculated with pySCF) are provided

1D KS: my implementation of 1D-DFT for harmonic oscillator tutorial : https://github.com/tamuhey/python_1d_dft

Turtles: alien turtle invasion game 

pw_dft: (work in progress) my simple plane wave dft code, inspired by PyPWDFT and lecture notes here (https://github.com/ifilot/pwdft-lecture-notes)
